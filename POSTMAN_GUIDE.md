## 🚀 Getting Started

### Prerequisites

- **Python 3.11+** with conda environment
- **Postman** (Desktop or Web version)
- **Server running** on `http://localhost:8000`

### Starting the Server

```powershell
# 1. Activate conda environment
conda activate "d:\Projects2.0\Valuenaire\.conda"

# 2. Navigate to project directory
cd d:\Projects2.0\Valuenaire\Re

# 3. Start the FastAPI server
uvicorn app.main:app --reload --host 0.0.0.0 --port 8000

# Alternative: Direct Python run
python -m app.main serve --port 8000
```

### Verify Server is Running

Open browser: `http://localhost:8000/docs` → Should show Swagger UI

## 🛠️ Setting Up Postman

### Step 1: Create a New Collection

1. Open Postman
2. Click **Collections** → **+ New Collection**
3. Name it: `AI-CA API`
4. Add description: `Agentic AI Chartered Accountant RAG System`

### Step 2: Configure Collection Variables

Go to **Collection Settings** → **Variables** tab and add:

| Variable | Initial Value | Current Value |
|----------|---------------|---------------|
| `base_url` | `http://localhost:8000` | `http://localhost:8000` |
| `client_id` | `test_user` | `test_user` |
| `auth_token` | `your_jwt_token_here` | - |

### Step 3: Set Default Headers

In **Collection Settings** → **Pre-request Script**:

```javascript
// Auto-generate request ID if not set
if (!pm.request.headers.has("X-Request-ID")) {
    pm.request.headers.add({
        key: "X-Request-ID",
        value: "req_" + Date.now() + "_" + Math.random().toString(36).substr(2, 8)
    });
}
```

### Step 4: Import OpenAPI Spec (Optional)

1. Go to `http://localhost:8000/openapi.json`
2. Copy the JSON content
3. In Postman: **Import** → **Raw Text** → Paste JSON
4. This auto-generates all endpoint requests

### 📤 File Upload

**Upload Excel/CSV/JSON files for analysis**

```
POST {{base_url}}/v1/ai-ca/upload
```

**Content-Type:** `multipart/form-data`

**Form Data Fields:**
| Key | Type | Required | Description |
|-----|------|----------|-------------|
| `file` | File | ✅ Yes | The file to upload |
| `client_id` | Text | ✅ Yes | User/client identifier |
| `ingest_all` | Text | No | `true` (default) or `false` |

**Example in Postman:**
1. Method: `POST`
2. URL: `{{base_url}}/v1/ai-ca/upload`
3. Body → **form-data**
4. Add fields:

   - `client_id`: `test_user`

### 🔍 Query Data

**Execute analytical queries on uploaded data**

```
POST {{base_url}}/v1/ai-ca/query
```

**Content-Type:** `application/json`

**Request Body:**
```json
{
    "client": "test_user",
    "query": "What was the total revenue in FY21?",
    "dataset_id": null,
    "session_id": null,
    "use_cache": true
}
```

**Request Body Fields:**
| Field | Type | Required | Description |
|-------|------|----------|-------------|
| `client` | string | ✅ Yes | Client/user identifier |
| `query` | string | ✅ Yes | Natural language question |
| `dataset_id` | string | No | Specific dataset to query |
| `session_id` | string | No | Conversation session ID |
| `use_cache` | boolean | No | Use cached results (default: true) |

**Sample Success Response:**
```json
{
    "success": true,
    "result": "Based on the Income Statement data, the total revenue in FY21 was ₹76.21 Million (76,210,000 INR).",
    "method": "sql_duckdb",
    "explanation": "Executed SQL aggregation on income_statement dataset",
    "error": null,
    "query_id": "qry_86540000_abc12345",
    "metadata": {
        "dataset_id": "test_user:doc_86533776_9d8caf:income_statement",
        "route": "TRACK_DATA",
        "raw_value": 76210000
    }
}
```

**Query Types Supported:**
- ✅ Aggregations (SUM, AVG, COUNT, MIN, MAX)
- ✅ Comparisons ("compare revenue between years")
- ✅ Calculations ("calculate profit margin")
- ✅ Summaries ("summarize the balance sheet")
- ✅ Trends ("show revenue trend over time")

## 📦 Response Envelope Format

All API responses follow this consistent envelope format:

```json
{
    "status": "ok | error",
    "request_id": "req_<timestamp>_<random>",
    "data": { ... } | null,
    "error": {
        "code": "ERROR_CODE",
        "message": "Human-readable message"
    } | null
}
```

### Status Codes

| HTTP Code | Status | Description |
|-----------|--------|-------------|
| `200` | `ok` | Success |
| `400` | `error` | Invalid input / Bad request |
| `429` | `error` | Rate limit exceeded |
| `500` | `error` | Internal server error |

### Error Codes

| Code | Description |
|------|-------------|
| `INVALID_INPUT` | Validation failed (missing/invalid fields) |
| `RATE_LIMIT_EXCEEDED` | Too many requests |
| `INTERNAL_ERROR` | Server-side error |
| `INVALID_JSON` | Malformed JSON in request |
| `MISSING_ACTION` | ZMQ request missing action field |

## ✅ Testing Scripts

Add these to the **Tests** tab in Postman:

### Basic Envelope Validation

```javascript
// Test 1: Response has valid envelope structure
pm.test("Response has valid envelope", function() {
    const json = pm.response.json();
    pm.expect(json).to.have.property("status");
    pm.expect(json).to.have.property("request_id");
    pm.expect(json.request_id).to.be.a("string").and.not.empty;
});

// Test 2: Status is 'ok' for success
pm.test("Status is ok", function() {
    pm.expect(pm.response.json().status).to.eql("ok");
});

// Test 3: HTTP status code is 200
pm.test("Status code is 200", function() {
    pm.response.to.have.status(200);
});

// Test 4: Response time is acceptable
pm.test("Response time is less than 5s", function() {
    pm.expect(pm.response.responseTime).to.be.below(5000);
});
```

### Health Check Tests

```javascript
pm.test("Health check returns component status", function() {
    const data = pm.response.json().data;
    pm.expect(data).to.have.property("components");
    pm.expect(data.components).to.have.property("api");
    pm.expect(data.components.api).to.eql("ok");
});
```

### Upload Tests

```javascript
pm.test("Upload returns doc_id", function() {
    const data = pm.response.json().data;
    pm.expect(data).to.have.property("doc_id");
    pm.expect(data.doc_id).to.match(/^doc_\d+_[a-f0-9]+$/);
});

pm.test("Upload returns dataset_ids array", function() {
    const data = pm.response.json().data;
    pm.expect(data).to.have.property("dataset_ids");
    pm.expect(data.dataset_ids).to.be.an("array");
});

// Save doc_id for subsequent requests
if (pm.response.json().status === "ok") {
    pm.collectionVariables.set("last_doc_id", pm.response.json().data.doc_id);
}
```

### Query Tests

```javascript
pm.test("Query returns result", function() {
    const json = pm.response.json();
    pm.expect(json).to.have.property("success");
    pm.expect(json).to.have.property("query_id");
});

pm.test("Query method is specified", function() {
    const json = pm.response.json();
    pm.expect(json).to.have.property("method");
    pm.expect(["sql_duckdb", "pandas", "llm_direct", "rag:semantic", "web:search"])
      .to.include(json.method);
});
```

### Error Response Tests

```javascript
pm.test("Error response has error object", function() {
    if (pm.response.json().status === "error") {
        const error = pm.response.json().error;
        pm.expect(error).to.have.property("code");
        pm.expect(error).to.have.property("message");
    }
});
```

## 🔧 Troubleshooting

### Common Issues

| Issue | Cause | Solution |
|-------|-------|----------|
| `Connection refused` | Server not running | Start server with `uvicorn` |
| `422 Unprocessable Entity` | Missing required fields | Check request body schema |
| `429 Too Many Requests` | Rate limit hit | Wait 60 seconds |
| `500 Internal Error` | Server exception | Check server logs |
| `CORS error` | Cross-origin blocked | Server has `*` CORS, check browser |

### Debug Mode

Start server with debug logging:
```powershell
$env:AICA_DEBUG = "true"
uvicorn app.main:app --reload --log-level debug
```

## 📂 Log Folder Structure

All logs are stored in `data/logs/` with client-specific subfolders:

```
data/logs/
├── uploads/                     # File upload logs
│   ├── test_user/
│   │   └── 2026-01-22/
│   │       ├── req_12345_abc.json
│   │       └── req_12346_def.json
│   └── other_client/
│       └── 2026-01-22/
│           └── req_12350_ghi.json
├── queries/                     # Query execution logs
│   └── test_user/
│       └── 2026-01-22/
│           └── req_12360_xyz.json
├── errors/                      # Error logs
│   └── test_user/
│       └── 2026-01-22/
│           └── req_error_123.json
├── requests/                    # General API requests
│   └── system/
│       └── 2026-01-22/
│           └── req_health_456.json
└── misc/                        # Other logs
    └── system/
        └── 2026-01-22/
```
